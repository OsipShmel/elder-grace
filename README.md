# Elder Grace

Инструменты и нативный движок для переноса Windows-игр на macOS (Apple Silicon) поверх **легально купленной копии** пользователя. Репозиторий не содержит кода и данных игр.

- Оригинал под CrossOver/GPTK — эталон для замеров и сравнений.
- Shim внутри Wine — наблюдаем и подменяем графику, получаем цифры на живой игре.
- Нативный рантайм на Rust + Metal — долгосрочный путь.

Первая тестовая цель — Elden Ring, она живёт в соседнем репозитории `../grace-eldenring/`.
